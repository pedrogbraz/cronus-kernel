## O QUE É O CRONUS

Uma **linguagem de programação declarativa** compilada em Rust. Um arquivo `.cronus` vira um app web completo: servidor HTTP, banco SQLite, API REST, GraphQL, UI renderizada, auth JWT, docs automáticos — tudo num binário de ~7MB.

```cronus
app "Meu App" {
  stack fullstack
  port 3000
  database sqlite "./data.db"
}

entity Task {
  title string required
  status enum ["todo", "done"] required
}

page "/" type:custom {
  section table style:dark {
    columns "Title, Status"
    bind Task { query all }
  }
}
```

Isso gera: servidor na porta 3000, tabela Task no SQLite, CRUD API em /api/tasks, página com tabela de dados ao vivo, auth, docs em /docs.

## O QUE FOI FEITO NESTA SESSÃO

### 1. Linguagem — Novas Features
- **Doc-comments `///`** — parsed no AST com `@tags` estruturados. Funciona em Entity, Field, Page, Section, Api, Route, App.
- **Constitution block** — `constitution { must "..." never "..." }` dentro do app block. Validado contra o AST.
- **`shared` keyword** — `entity X shared {}` pula filtro _owner_id (dados visíveis a todos users autenticados).
- **Webhooks** — `webhook /entity { on create -> POST "url" }`. Dispara em background após mutations.
- **SQL validation** — P040/P041 rejeitam identificadores inválidos e palavras reservadas SQL no parser.

### 2. Enforcement — 13 Regras Inquebraveis
```
C001  no-dead-text         Métricas hardcoded em templates         ERROR
C002  no-sensitive-render  Campos sensitive no HTML/API            ERROR  
C003  bind-or-empty        Seções de dados sem bind/items          ERROR
C010  no-dead-links        Links internos pra rotas inexistentes   ERROR
C011  no-dead-ui           Botões sem action handler               WARNING
C012  form-submit-handler  Forms sem submit                        WARNING
C020  no-orphan-reload     location.reload() no código             ERROR
C030  shared-entity-auth   Mutação pública em entity shared        ERROR
C031  no-sensitive-select  Campo sensitive em columns/bind         ERROR
P040  identifier-valid     Identificador SQL inválido              FATAL
P041  sql-reserved         Palavra reservada SQL como nome         FATAL
      no-fake-state        "Loading" em HTML estático              WARNING
      no-hardcode-user     "System Admin" em HTML                  WARNING
```

### 3. AI Context Protocol
- **`/api/_context`** — endpoint JSON com TUDO do projeto (entities, campos, tipos, relações, regras, saúde, memória)
- **`cronus context --for-claude`** — Markdown otimizado (~40 linhas)
- **`cronus context --section entities`** — filtra por seção
- **`.cronus/memory.db`** — SQLite com sessions, decisions, anti_patterns, changelog, business_rules
- **`cronus handoff --summary "..."`** — fecha sessão AI

### 4. Debug System
- **Debug overlay** — Cmd+Shift+D ou `?debug=1`. Tabs: Network (waterfall), Errors (stack traces), Info (route, auth, CSP)
- **Backend traces** — X-Response-Time, X-Request-Id, X-Query-Count em toda response
- **`/api/debug/traces`** — buffer circular de requests
- **`/api/debug/stream`** — SSE de eventos debug
- **`data-cronus-debug`** — atributos JSON nos sections renderizados
- **`cronus debug`** — modo com overlay + logs coloridos no terminal

### 5. Segurança
- **Argon2id** para passwords (fallback SHA-256 para migração)
- **Rate limiting** ativo: 10/60s auth, 100/60s API
- **CSP nonces** per-request em todo `<script>`
- **Audit trail** com hash chain SHA-256 + diff (before/after)
- **Data isolation** via _owner_id + `shared` keyword

### 6. DevTools
- **`cronus doctor`** — 10 checks de saúde
- **`cronus changelog`** — diff semântico do AST
- **`cronus graph`** — diagrama Mermaid de relações

- **`cronus generate "descrição"`** — gera .cronus a partir de texto
- **`cronus verify-audit`** — verificação offline da hash chain
- **`cronus debug audit`** — audit trail com diffs coloridos

## REGRAS INVIOLÁVEIS

1. **ZERO hardcode** — tudo vem do DB ou API. Lint C001 bloqueia build.
2. **ZERO dados fake** — DB começa vazio. Empty states obrigatórios.
3. **ZERO location.reload()** — CRONUS.reload() para soft refresh. Lint C020 bloqueia.
4. **Sensitive nunca no output** — password nunca aparece em HTML/API. Lint C002/C031.
5. **Tudo em tempo real** — mutations disparam SSE + auto-reload. SPA navigation obrigatória.
6. **Código se documenta** — `///` doc-comments entram no AST e geram /docs.
7. **Constitution inline** — regras de negócio no código, validadas automaticamente.

## BUGS CONHECIDOS / LIMITAÇÕES

1. `cronus build` trava após output (tokio runtime não fecha em cmd_build). Workaround: usar `timeout 10 cronus build`.
2. Rate limiter dropa TCP ao invés de retornar 429 — funcional mas não ideal.
3. `cronus brief` mostra "Unknown" para project metadata (precisa constitution.toml + objective.toml).
4. Charts sem dados reais usam barras decorativas (placeholder) — aceitável.
5. `@ai` tag parsing funciona mas nenhum template no Nova Core usa ainda.
